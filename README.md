# 🏥 Healthcare Analytics Dashboard — Power BI

## 📌 Overview
Power BI executive dashboard for MetroCare Hospital tracking patient, appointment, and revenue insights.

## 🎯 Objective
To help hospital management track key operational metrics billing trends, patient distribution, doctor performance, and cancellation patterns — through a set of interactive report pages for faster, data-driven decision-making.

## 📄 Report Pages
This `.pbix` file includes multiple report pages, each focused on a different area of hospital operations:
* **Executive Overview** — high-level KPIs and revenue insights
* **Patient Insights** — patient category and demographic breakdown
* **Doctor and Department Performance** — doctor-wise and department-wise analysis
* **Bills by Doctors** — billing breakdown per doctor
* **Appointments by Department** — appointment volume across departments
* **Appointment Details** — status-wise appointment tracking (Completed, Cancelled, No-show, Scheduled)
* **Patients Rank** — patient ranking by billing/visits
* **MetroCare Hospital Dashboard** — consolidated single-view summary combining key visuals from all pages

## ✅ Key Features
* KPI tracking with Month-over-Month (MoM) trend indicators
* Total Bills trend analysis by month
* Doctor-wise Cancellation Rate analysis with dynamic conditional formatting
* Department-wise revenue breakdown
* Patient Category-wise billing (General, Corporate, VIP)
* Payment Mode analysis (Cash, Card, Insurance Claim)
* Appointment Status breakdown (Completed, Cancelled, No-show, Scheduled)
* Interactive filters/slicers: Department, Doctor, Patient Category, YearMonth

## 🛠️ Tools & Skills Used
* Microsoft Power BI
* Power Query (data cleaning & transformation)
* DAX (calculated measures & KPIs)
* Data Modeling
* Conditional Formatting
* Data Visualization

## 💡 Key Insights
* General category patients contribute the largest share of total billing
* Cancellation rates vary significantly across doctors and departments
* A small number of doctors account for a disproportionately high share of cancellations
* Payment modes are fairly distributed across Cash, Card, and Insurance Claims

## 🚀 How to View
1. Download the `.pbix` file
2. Open it using [Power BI Desktop](https://powerbi.microsoft.com/desktop/) (free to download)
3. Use the page tabs at the bottom to explore each report page
4. Interact with the filters and visuals on any page
